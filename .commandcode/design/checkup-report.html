// PRIORITY ISSUES
P0 — BLOCKING

No visible focus indicators on interactive elements

Form inputs are the only elements with focus:ring-1 focus:ring-accent. The CTA button, header nav links ("Events", "Apply"), footer links, filter pills, pagination prev/next, dark mode toggle, "Learn more about PWV", "View event details", and sort toggle all lack explicit focus styles. Keyboard users get zero visual feedback when tabbing.

FIX: /design interaction — Add focus-visible:ring-2 focus-visible:ring-accent focus-visible:ring-offset-2 to all interactive elements.
P1

No skip-to-content link

Keyboard users must tab through the entire header (logo, nav, CTA, dark mode toggle) before reaching main content on every page load.

FIX: Add a visually-hidden skip link as the first focusable element in document.tsx. Show on focus at top of viewport.
P1

Body transition-colors not gated behind prefers-reduced-motion

The body element has transition-colors duration-200 without a prefers-reduced-motion: no-preference wrapper. The SemverFlourish correctly respects the query, but the body transition does not.

FIX: /design motion — Wrap in @media (prefers-reduced-motion: no-preference).
P2

Submit button disabled until AI summary completes

The submit button is disabled when !summary. If AI summarization fails silently, the user has no alternate path. No timeout fallback exists.

FIX: Add a timeout that re-enables the button with a warning, or offer "Submit without summary" as a fallback.
P2

No ARIA attributes on admin filter pills

Status filter pills lack role, aria-current, or aria-pressed. Screen readers cannot determine which filter is active.

FIX: Add role="list" on container, aria-current="page" on active pill.
P2 — WATCH

font-serif maps to DM Sans (same as sans)

The Tailwind theme defines --font-serif as "DM Sans Variable" — the same as --font-sans. Source Serif 4 is in dependencies. Either wire it up or remove the token.

P2 — WATCH

theme-color meta tags don't match CSS bg values

#f7f1dc (light) and #090907 (dark) in meta tags vs #fff9da and #000000 in CSS. Subtle color flash possible on some browsers.
